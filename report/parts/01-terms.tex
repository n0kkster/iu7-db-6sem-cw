\numberlesssection{ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ}

В настоящем отчете о НИР применяют следующие сокращения и обозначения.

\begin{itemize}
    \item API --- Application Programming Interface --- программный интерфейс приложения
    \item СУБД --- Система Управления Базами Данных
    \item ИТ --- Информационные Технологии
    \item SRE --- Site Reliability Engineering --- дисциплина, разработанная для 
    обеспечения надежности высоконагруженных информационных систем
    \item UUID --- Universally Inique Identifier --- универсальный уникальный идентификатор
\end{itemize}
